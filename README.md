### 📺 Stereo Output Modes

| ID | Mode | Description / Recommended Displays |
| :---: | :--- | :--- |
| **1** | **Side-by-Side** | Half-SBS, 3D TVs, VR desktop viewers, and SBS players |
| **2** | **Top / Bottom** | Over/Under 3D displays |
| **3** | **Line Interleave** | Passive polarized 3D monitors and TVs |
| **4** | **SR Displays** | Autostereoscopic, lenticular, and SR Displays (Samsung Odyssey, Acer ,etc.) |
| **5** | **Checkerboard** | Legacy DLP 3D-Ready TVs |
| **6** | **VR Full-Res** | Full per-eye resolution rendered into a dual-width canvas (`2W x H`) |

# **🛠️ Installation Guide**

Extract the contents of the downloaded .zip file.

Copy dinput8.dll into the main directory of your game (where game.exe is located).

Launch the game and open the REFramework overlay.

Select the profile dropdown menu (e.g., OnimushaStereo3D).

Check Enable 3D.

Select the Stereo output mode that matches your display or setup.

# **⚙️ Troubleshooting & Recommended Settings**

Anti-Aliasing: Switch to TAA (if you experience bugs or artifacts with DLSS)

Motion Blur = OFF

VSYNC = OFF

Display Mode: Exclusive Fullscreen or Borderless Windowed (matching your 3D output display)
