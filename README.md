### 📺 Stereo Output Modes

| ID | Mode | Description / Recommended Displays |
| :---: | :--- | :--- |
| **1** | **Side-by-Side** | Half-SBS, 3D TVs, VR desktop viewers, and SBS players |
| **2** | **Top / Bottom** | Over/Under 3D displays |
| **3** | **Line Interleave** | Passive polarized 3D monitors and TVs |
| **4** | **SR Displays** | Autostereoscopic, lenticular, and SR Displays (Samsung Odyssey, Acer ,etc.) |
| **5** | **Checkerboard** | Legacy DLP 3D-Ready TVs |
| **6** | **VR Full-Res** | Full per-eye resolution rendered into a dual-width canvas (`2W x H`) |

## 🛠️ Installation Guide

1. Extract the contents of the downloaded `.zip` file.
2. Copy `dinput8.dll` into the main directory of your game (where `game.exe` is located).
3. Launch the game and open the REFramework overlay.
4. Check **Enable 3D**.
5. Select the **Stereo output** mode that matches your display or setup.

## ⚙️ Recommended Game Settings

| Setting | Recommended Value | Notes |
| :--- | :---: | :--- |
| **Anti-Aliasing** | **TAA** | Switch to TAA if experiencing bugs or artifacts with DLSS |
| **Motion Blur** | **OFF** | Disabling prevents 3D motion artifacts and ghosting |
| **VSYNC** | **OFF** | Reduces latency and frame-pacing issues |
| **Display Mode** | **Exclusive Fullscreen / Borderless** | Must match your 3D output display |
